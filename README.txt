INSANE RUMMY TRACKER - installable app (PWA)

1. Upload ALL files (no folders needed)  to any HTTPS host,
   e.g. Netlify Drop (app.netlify.com/drop) or GitHub Pages.
2. Open the link in Chrome on Android, tap the menu (3 dots) > "Install app" / "Add to Home screen".
3. Open it once while online so fonts load; after that it works offline.

Your data is stored on the device (browser storage for that site). Use the in-app Export to back it up.
